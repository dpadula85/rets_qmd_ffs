Notes
=====

This folder contains rPSB force fields fitted with the Joyce program.
The `ret.top` file is an example topology, in which any of the include `.itp`
files can be incorporated to model a different rPSB.

These QMD-FFs are electronic supporting information for the paper
**[A set of Quantum-Mechanically Derived Force Fields for Natural and
Synthetic Retinal Photoswitches](URL)**
submitted to _J. Chem. Theory Comput._ by R. E. Daoud, S. Veglianti, A. Piras,
A. Semmeq, S. Giannini, G. Prampolini, and D. Padula.

For questions or assistance, please get in touch with the authors at the email
address specified on the paper.
